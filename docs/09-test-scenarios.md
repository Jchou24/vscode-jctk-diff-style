# 09. 測試情境

- 每一條情境：做什麼 → 看到什麼
- 驗證
    - **自動**：`tests/` 裡名稱帶著同一個編號（`[DS-01]`）的測試守著它
        - 單元測試驗規則
        - 冒煙測試（`tests/extensionSmoke.test.ts`）用正式的打包選項打包、交給假的 `vscode` 載入，驗只有接上 VS Code 才看得到的那些
    - **手動**：只能在真的 VS Code 裡看（畫面、真的 diff 編輯器），走法見最後一節
- 編號由 `tests/scenarioRegistry.test.ts` 對照
    - 標「自動」的每一條，`tests/` 裡至少有一條測試帶著它
    - 測試帶的每一個編號，這裡都有、而且標「自動」
- 在本目錄 `pnpm test` 就跑得起來

## 手動驗的那幾條怎麼走

- 前置：`pnpm install:vscode`，VS Code 裡 Reload Window
- DS-14
    - 命令「開啟範例 diff」，視窗寬到兩欄並排
    - 新增那一側改動的字有綠框、刪除那一側有紅框
- DS-15
    - 把視窗拉窄到 diff 自動切成單欄，或設定 `diffEditor.renderSideBySide: false`
    - 新增那一側有框；刪除的那幾行沒有框
- DS-23
    - 開範例 diff，參數組選有註解色的那一組（ex 內建的亮色）
    - 註解裡被框到的字換成註解色；程式碼裡被框到的字（`Jc`、`true`）不換
- DS-49
    - 開設定面板，點「整段新增 / 刪除也框」那一列右邊的空白
    - 勾選不變、diff 的框線不變；點勾選框或旁邊的字才會切換
- DS-50
    - 把設定面板拉窄
    - 每條滑桿在名字的下一行，從取色器那一欄開始
- DS-54
    - 參數組選有行號色的那一組，開範例 diff
    - 紅 / 綠行號欄上的行號讀得到；游標移到某一行，那一行的行號比其他行亮
- DS-57
    - 開設定面板、開範例 diff
    - 面板最上面的「Language」選「繁體中文」
        - 面板的標題、勾選框、按鈕換成中文
        - 範例 diff 的註解換成中文
        - 狀態列的提示換成中文
        - VS Code 自己的選單仍是原本的語言
    - 改名、刪除參數組
        - 輸入框與確認通知是中文
    - 命令選擇區打 `Jctk Diff Style`
        - 命令名仍跟著 VS Code 的顯示語言
    - 選回「跟著 VS Code」
        - 上面幾處回到 VS Code 的顯示語言（沒裝繁中語言包的 VS Code 是英文）
    - 已經存在設定裡的參數組名字不跟著換：那是資料，不是介面文字
