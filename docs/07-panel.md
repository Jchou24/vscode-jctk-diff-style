# 07. 設定面板

## 開法

- diff 分頁標題列的調色盤按鈕：只在 diff 編輯器裡出現
- 命令「開啟設定面板」
- 狀態列切換選單的最後一項
- 開在旁邊一欄；已經開著就帶到前面

---

## 擴充與面板之間的訊息

- 兩邊跑在不同的環境、只能互傳 JSON
    - ⇒ 收到的一律當成不可信，經守門收斂
    - 訊息種類只定義一次，兩邊共用
- 型別單一來源：`PanelMessageTypes`、`IPanelState`、`ParsePanelMessage`、`ParseStateMessage` 見 `src/panelMessages.ts`

### 擴充 → 面板

- 狀態（`State`）
    - 參數組清單
    - 目前那一組的名字
    - 目前的主題
    - 參數組與顏色寫在哪一層
    - 被蓋掉的鍵
    - 介面語言的設定（`auto`、`en`、`zh-tw`）與實際用的語言
    - 翻譯表：實際用的那個語言的（見 [01-overview.md](01-overview.md)〈介面語言〉）
        - 顯示語言是英文、或那個語言沒有翻譯 ⇒ 沒有這一欄，面板用英文
        - 值有一個不是字串 ⇒ 整份不要
- 什麼時候送
    - 面板要（`Ready`）
    - 清單或目前那一組換了（新增、改名、刪除、切換）
    - 參數組被別處改了
    - 主題換了
    - 被蓋掉的鍵變了
- 不送的時候：面板送值回來（`Update`）時
    - 拖動中重畫面板，正在拖的控制項會被換掉
- 面板收到認不得的狀態（缺欄位、寫入的那一層認不得）⇒ 不重畫

### 面板 → 擴充

| 訊息          | 什麼時候送                             | 擴充做什麼                                                                            |
| ------------- | -------------------------------------- | ------------------------------------------------------------------------------------- |
| `Ready`       | 面板載入完成                           | 送一份狀態                                                                            |
| `Update`      | 任何一個控制項動了；帶目前那一組的整份 | 換掉目前那一組、套用、存檔；不回送狀態                                                |
| `Select`      | 下拉選了另一組                         | 切換（見 [05-presets.md](05-presets.md)）                                             |
| `Add`         | 「複製成新的一組」                     | 問名字、新增並切過去                                                                  |
| `Rename`      | 「改名」                               | 問名字、改名                                                                          |
| `Remove`      | 「刪除」                               | 確認後刪除                                                                            |
| `OpenSample`  | 「開啟範例 diff」                      | 開範例 diff（見 [08-entry-points.md](08-entry-points.md)）                            |
| `SetLanguage` | 「語言」下拉選了另一個                 | 寫進使用者設定；設定變更事件再套用（見 [01-overview.md](01-overview.md)〈介面語言〉） |

- `Update` 帶的參數組也經過收斂：缺的欄位用目前那一組補
    - 沒有名字 ⇒ 擋下
    - 名字不是目前那一組 ⇒ 略過並記進診斷紀錄
- 認不得的訊息 ⇒ 記進診斷紀錄、不處理
- 處理失敗 ⇒ 記進診斷紀錄

## 畫面

- 收到狀態就整個重畫；每個控制項一動就把目前那一組整份送回
- 畫面上的字：每次收到狀態，先用裡面的翻譯表設定 `@vscode/l10n` 再畫
    - 介面語言可以在面板開著時換 ⇒ 每次都設，不是只設第一次
    - 沒有翻譯表（英文）時設成空的：回到原文
    - `<html lang>` 設成實際用的語言
- 由上到下
    - 語言：下拉選「跟著 VS Code」或某一個語言，底下一句說明命令名跟著 VS Code
        - 放最上面：介面是看不懂的語言時，也找得到它
        - 各語言寫成那個語言自己的字（English、繁體中文）：介面是哪個語言都認得出來
    - 參數組：下拉切換、複製成新的一組、改名、刪除、開啟範例 diff
    - 被蓋掉的警告（有才顯示）
    - 框線：畫框線、兩側的顏色、粗細、樣式、圓角、整段新增 / 刪除也框、只改了空白的也框
    - 底色：VS Code 內建 diff 的每一個底色
    - 註解色：不換、顏色
    - 行號色：不換、一般的行號、游標所在那一行
    - 最下面一行：參數組與顏色寫在哪一層、哪個主題那一格
- 顏色那一列
    - 第一行：名字、取色器、透明度百分比、色碼
    - 第二行：透明度滑桿，從取色器那一欄開始
        - 擠在同一行時，面板一窄滑桿就只剩一點點
    - 取色器、滑桿、百分比任何一個動了，三者與色碼一起更新
    - 色碼與透明度的換算見 `src/colorHex.ts`
- 粗細、圓角：第一行名字與目前的值，第二行滑桿
- 勾選框：只有框與旁邊的名字點得到
    - 整列都包在可點的範圍裡時，點到那一列右邊的空白也會切換，使用者察覺不到就改了參數
- 「畫框線」關掉：框線那一節其餘控制項變灰、不能操作
- 註解色、行號色的「不換」
    - 勾起來：拿掉那個欄位，下面的控制項變灰
    - 取消勾選：用畫面上那個顏色（預設是內建的那個讀得到的顏色）
- 樣式跟著 VS Code 主題的 CSS 變數：明暗主題都對
- 安全
    - Content-Security-Policy 只允許帶 nonce 的腳本與 inline 樣式
    - 只從擴充的 `dist/` 載入資源
- 面板每次載入（含切走又切回來）都會送 `Ready` 要一份狀態
