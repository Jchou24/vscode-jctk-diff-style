# 08. 啟用、命令、狀態列、範例 diff、診斷紀錄

## 啟用

- VS Code 啟動完成就啟用（`onStartupFinished`）：每個視窗都會啟用
- 啟用時
    - 讀參數組（見 [06-settings.md](06-settings.md)）
    - 套用目前那一組：畫框線、寫顏色、更新狀態列
    - 套用介面語言（見 [01-overview.md](01-overview.md)〈介面語言〉）：其他每一步取的字都是這個語言
    - 診斷紀錄記一行：幾組參數、寫在哪一層、目前那一組、主題、介面語言
- 停用時：還沒寫的顏色與參數組寫完

---

## 命令

- 單一來源：`package.json` 的 `contributes.commands`；程式裡的 id 見 `extension.ts` 的 `CommandIds`
- 命令名只跟著 VS Code 的顯示語言，不跟著這支擴充的介面語言（見 [01-overview.md](01-overview.md)〈介面語言〉）；下表是繁中的

| 命令               | 做什麼                                                              |
| ------------------ | ------------------------------------------------------------------- |
| 開啟設定面板       | 見 [07-panel.md](07-panel.md)                                       |
| 切換參數組         | 快速選單：每一組（目前那一組標「目前」）＋ 最後一項「開啟設定面板」 |
| 開啟範例 diff      | 見下方〈範例 diff〉                                                 |
| 移除寫進設定的顏色 | 見 [06-settings.md](06-settings.md)〈移除顏色〉                     |
| 開啟診斷紀錄       | 打開 Output 面板的「Jctk Diff Style」                               |

- 命令擲錯：記進診斷紀錄，再往外丟
    - 不記的話，VS Code 只會跳一個沒有原因的錯誤通知

## 狀態列

- 有看得到的 diff 分頁才顯示
- 顯示目前那一組的名字
- 點了 ⇒ 切換參數組

---

## 範例 diff

- 調參數時一次看得到所有狀況：開一個 diff 分頁，兩側是唯讀的虛擬文件
    - 文件用擴充自己的 scheme，副檔名 `.ts`：照 TypeScript 上色
- 有哪些案例：單一來源 `src/sampleLines.ts` 的檔頭
- 每一個案例框到哪幾個字：`tests/sampleLines.test.ts` 釘住
    - 比對設定照使用者的 `diffEditor.ignoreTrimWhitespace: false`
    - 改了範例的內容（或比對規則）而某個案例不見了，那支測試會紅

---

## 診斷紀錄

- Output 面板的「Jctk Diff Style」
- 為什麼要有：extension host 會吞掉事件處理器擲出的例外，不記就沒有任何痕跡
- 記什麼
    - 啟用時的摘要
    - 參數組被別處改了、重新讀入
    - diff 分頁找不到兩側：附上看得到的編輯器與它們的欄號
    - 面板送來認不得的訊息、送狀態給面板失敗、處理面板訊息失敗
    - 每個進入點的失敗（重畫框線、寫入顏色、儲存參數組、命令）：含堆疊
