# 05. 參數組

## 一組管什麼

- 型別單一來源：`IDiffStylePreset`、`IDiffColors`、`IBorderOptions`、`ILineNumberColors` 見 `src/presetModel.ts`
    - 每個欄位的意思寫在那裡的 JSDoc
- 各欄位落在哪裡

| 欄位           | 管什麼                                                                           | 落在哪裡                                                                    |
| -------------- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `name`         | 參數組的名字，同一份清單裡唯一                                                   | 切換、改名都靠它找                                                          |
| `colors`       | VS Code 內建 diff 的底色                                                         | 設定 `workbench.colorCustomizations`（見 [06-settings.md](06-settings.md)） |
| `border`       | 擴充自己畫的框線：開關、兩側的顏色、粗細、樣式、圓角、整段也框、只改了空白的也框 | decoration（見 [03-diff-ranges.md](03-diff-ranges.md)）                     |
| `commentColor` | diff 裡註解中改動的字的顏色；沒有就不換                                          | decoration（見 [04-comment-color.md](04-comment-color.md)）                 |
| `lineNumbers`  | 一般的行號、游標所在那一行的行號；沒有就不換                                     | 設定 `workbench.colorCustomizations`                                        |

- 參數組存在設定 `jctkDiffStyle.presets`，目前那一組的名字存在 `jctkDiffStyle.activePreset`
    - 存在哪一層見 [06-settings.md](06-settings.md)

## 內建的參數組

- 清單是空的、或一筆合法的都沒有 ⇒ 用 `GetDefaultPresets`
- 名字照介面語言取：繁中是亮色、暗色，英文是 Bright、Dark
    - 擴充端把翻好的名字交給 `NormalizePresets`；沒給時用 `GetDefaultPresetNames` 的英文
    - 還沒寫進設定時換介面語言：兩組當場改名（`RenameBuiltInPresets`），值與目前那一組不變
    - 寫進設定之後就是使用者的資料：換介面語言不跟著改名
    - `activePreset` 存的是另一個語言的名字 ⇒ 找不到，用第一組
- 亮色
    - 整行不上底色，只有改動的字與行號欄上色：改了幾個字的那一行最清楚
    - 框線用淡色、半透明、小圓角：框住改動的字，又不搶過字本身
    - 代價：整段新增 / 刪除裡的灰色註解疊在改動的字的底色上會變淡
    - ⇒ 預設換註解色、行號色，讓它們在 diff 底色上讀得到
        - 註解色：`READABLE_COMMENT_COLOR`
        - 行號色：`GetReadableLineNumbers`；游標所在那一行比一般的亮，才分得出來
        - 選色的理由寫在那兩個符號的 JSDoc
    - 值：`GetBrightColors`、`GetBrightBorder`
- 暗色
    - 改動的字暗：整段新增 / 刪除裡的註解最好讀
    - 代價：改動的字要靠框線才看得出來 ⇒ 框線用飽和的紅綠（`GetDarkBorder`）
    - 註解色、行號色不換
- 亮色那一組也是讀回來的參數組缺欄位時補的值

## 讀回來的值怎麼收斂

- 設定是人可以手改的 ⇒ 讀回來的值一律當成不可信，收斂成完整的形狀
- 不擲例外：改壞的欄位補預設，擴充照樣能用

| 讀到的                             | 收斂成                                                              |
| ---------------------------------- | ------------------------------------------------------------------- |
| 不是陣列                           | 內建的參數組                                                        |
| 一筆不是物件、沒有名字、名字是空白 | 丟掉這一筆                                                          |
| 名字頭尾有空白                     | 去掉                                                                |
| 名字重複                           | 只留第一筆                                                          |
| 丟完之後一筆都不剩                 | 內建的參數組                                                        |
| 顏色是 `#rrggbb` 或 `#rrggbbaa`    | 轉小寫留著                                                          |
| 顏色是其他寫法                     | 亮色那一組的值                                                      |
| 粗細、圓角是數字                   | 四捨五入、夾在範圍內（`BORDER_WIDTH_RANGE`、`BORDER_RADIUS_RANGE`） |
| 粗細、圓角不是數字                 | 亮色那一組的值                                                      |
| 框線樣式不認得                     | 亮色那一組的值                                                      |
| 開關不是布林                       | 亮色那一組的值                                                      |
| 註解色不是合法的顏色               | 不換                                                                |
| 行號色不是物件                     | 不換                                                                |
| 行號色是物件、其中一色不合法       | 那一色用讀得到的那一色補                                            |

- 面板送回來的參數組也經過同一套收斂，缺的欄位用目前那一組補（見 [07-panel.md](07-panel.md)）

## 新增、改名、刪除、切換

- 複製成新的一組
    - 名字預填 `<目前那一組> 複本`；已經有人用就往後編號（`複本 2`、`複本 3`…）
    - 新的一組是目前那一組的深拷貝，不共用任何物件
    - 新的那一組成為目前那一組
- 改名
    - 名字不能空白、不能與其他組同名；頭尾空白去掉
    - 按 Esc、或名字沒變 ⇒ 不動
- 刪除
    - 至少留一組：只剩一組時跳訊息、不刪
    - 跳確認對話框；沒按「刪除」⇒ 不動
    - 刪了之後，目前那一組換成第一組
- 切換
    - 面板的下拉、狀態列、命令都走同一條
    - 名字找不到 ⇒ 切到第一組
- 改了之後
    - 清單或目前那一組換了（新增、改名、刪除、切換）：套用、存檔、面板重畫
    - 只有值變了（面板拖動）：套用、存檔，面板不重畫
